Relay cut

Same trick, a few angles. On each clip, park the playhead and mark the start and end of the motion. Add a phase mark at a moment that should match, like the top of a backflip. Build then cuts from angle to angle through that motion.

Leave cuts blank for one slice per angle. A higher number bounces between angles.

Technical details

  
Preview uses the browser's own player, so scrubbing stays quick. Export runs a converter on this device (about 31 MB the first time, then it can work with no signal) and writes an H.264 MP4 at 1080p. One core does the encode, so a short reel can take a few minutes. Leave this page open. A 4K file that was not downscaled can run out of memory; the warning above is the one to trust. This is meant for Chrome or Safari on a Mac. GitHub Pages can't send the headers a multi-core converter needs, and a second offline worker would fight this app's, so export uses the same single-core converter as Video Converter.
